# SatsunicPlan v0.1.0-beta.1

First source beta for the React/TypeScript/Firebase delivery workspace.

## Available in this candidate

- Persisted work items, immutable document revisions and independently approved implementation contracts.
- Readiness recommendation, atomic claims, exact context, checkpoints, submissions and human review through shared UI/MCP services.
- Plane-derived roadmap, bounded reports, decisions and manual deployment records.
- Source-derived Ask interface with local help; no embedded model or agent execution runtime.
- Explicit human cloud API/client activation with project/Host/Origin validation and fail-closed configuration. Cloud agent connections remain unavailable.

## Validation

Node22 build and25 unit/config/provenance tests; isolated synthetic Firebase Rules/integration/MCP/Auth suite12 groups; actual cloud build UI using intercepted synthetic Auth/API across3 viewports and4 failure states. Local evidence is not live Firebase/client/provider acceptance. See docs/sp-prod-001-completion.md for limitations and independent review.

## Beta boundaries

This is a source prerelease, not a deployed or production-ready application certificate. Production deployment is blocked: satsunicplan billing is disabled, Firestore/Functions prerequisites are absent and no registered web app is available. No production URL is claimed by this release.

Public MCP OAuth, actual Codex/Claude/Antigravity/Kimi acceptance, GitHub/CI verification, full master A01–A64 coverage, broader lifecycle/knowledge/report/release features and production operations/restore/performance remain incomplete. Existing main frontend chunk warning remains. Local/default runtime uses isolated demo emulators; cloud activation requires verified settings and authorized rollout. Do not use the synthetic browser fixture build/settings as production configuration.

Plane Community source and AGPL notices/provenance are retained in vendor/plane-community, THIRD_PARTY_NOTICES.md and docs/plane-reuse-manifest.json.

Owner approved public source-beta distribution under AGPL. See root LICENSE and retained third-party notices; the full transitive distribution audit remains incomplete.
